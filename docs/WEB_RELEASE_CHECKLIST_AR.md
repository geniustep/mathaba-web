# بوابات إصدار موقع مثابة — 23 أكتوبر 2026

## تمثيل المشروع
- لا تُستخدم عبارات تجعل مثابة مشروعًا محليًا يتوسع لاحقًا: هي عالمية منذ التأسيس.
- لا روابط تنزيل متاجر إلا بعد إصدار مثبت وموقّع ومعتمد.
- المحتوى المحسوب ليس جدولًا رسميًا، ورواية ورش غير معتمدة بعد.
- الشعار مطابق لأصول Flutter (لا إعادة رسم).

## اختبارات آلية
- npm run build وnpm run typecheck.
- اختبار /ar و/en و/fr وجميع المسارات السبعة بكل لغة.
- /robots.txt و/sitemap.xml، metadata canonical وhreflang وOpenGraph وبيانات Organization.
- عدم ظهور أي نموذج يدّعي إرسال بريد أو تخزين موافقة بلا خدمة فعلية.

## فحوص نشر
- GitHub dev → Vercel Preview → اختبارات وتصحيح → main فقط عند النجاح.
- تحقق من HTTPS والتحويل apex→www، واستبعاد حلقة تحويلات.
- فحص الزحف والفهرسة بعد النشر باستخدام Google Search Console.
- التحقق بصريًا من 360 و390 و768 و1280 بكسل ومن لوحة المفاتيح وقراءة الشاشة.
- Lighthouse لقياس Core Web Vitals بدل إعطاء درجة غير مقاسة.

## ما يحتاج مراجعة بشرية
- الصياغة الفرنسية والإنجليزية.
- حالة المصدر الديني والقرآني، الحقوق والتراخيص.
- سياسة الخصوصية قانونيًا وقناة تواصل خاصة موثوقة.
- صور حقيقية من التطبيق على جهاز فعلي قبل إدراجها.
