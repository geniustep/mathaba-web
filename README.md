# مَثَابَة | MATHABA Web

موقع الويب المستقل لمشروع **مثابة**: رفيق إسلامي عالمي، مجاني بالكامل، بلا إعلانات، ويحترم الخصوصية.

## الحالة

**تأسيس المستودع فقط** — لم يُربط بـ Vercel ولم يُنشر على `mathaba.online` بعد. النشر وربط النطاق ينتظران تعليمات مستقلة.

## التطوير

- Next.js + TypeScript + App Router.
- تصميم مبدئي متجاوب، باللغة العربية، قابل لتوسيع اللغات.
- الشعار الكامل والرمز الأصليان من `geniustep/MATHABA`، فرع `dev`، بدون أي تعديل بصري.
- لا أدوات تحليل أو تتبع، ولا مفاتيح سرية في المستودع.

```bash
npm install
npm run dev
```

> هذا الموقع ليس إعلانًا عن إصدار التطبيق على المتاجر أو عن توفير مواقيت رسمية.
